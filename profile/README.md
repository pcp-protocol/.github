## Portable Context Protocol

PCP is an open protocol for AI context you own: your profile, memory and connections behind one URL you control, usable by any MCP client.
It is independent, free under Apache 2.0, and anyone can implement it without asking.

- **Spec:** [SPEC.md](https://github.com/pcp-protocol/pcp/blob/main/SPEC.md)
- **Site:** [pcp-protocol.github.io/pcp](https://pcp-protocol.github.io/pcp/)
- **Conformance suite:** [conformance/](https://github.com/pcp-protocol/pcp/tree/main/conformance)
- **Latest release:** [v0.3](https://github.com/pcp-protocol/pcp/releases/latest)
- **How decisions are made:** [GOVERNANCE.md](https://github.com/pcp-protocol/pcp/blob/main/GOVERNANCE.md)

### Implementations

- [TomaTío](https://tomatio.ai): reference implementation. A WordPress plugin that gives teams of people and AI agents a shared memory, with PCP export and import.
- [Refugio](https://github.com/Phantazein-apps/refugio): a local LLM that connects to any PCP context as an MCP client.

Listing is open to any implementation and is not an endorsement. No implementation owns PCP or has special standing. [Add yours](https://github.com/pcp-protocol/pcp/blob/main/README.md#implementations) with a pull request.
